EMBEDDED ASF CONTROL

内置 ASF 账号管理

直接通过 AstrBot 已登录的管理面板操作容器内 ASF；不需要 Firefox、NAS 端口映射或访问 127.0.0.1:1242。此处集成常用 Bot 管理操作，并非上游 ASF-ui 的全部设置。

保存「插件托管 ASF」模式并启动 ASF 后，点击刷新。

建议流程：创建本地 Bot 配置 → 保存托管模式 → 启动 ASF → 启用 Bot → 输入 Steam 密码（若需要）→ 启动 Bot → 收到 Steam Guard 要求时提交验证码 → 再次启动 Bot。登录授权仍需由账号持有人完成。密码与验证码不进入 QQ 推送、历史记录或 GitHub。
